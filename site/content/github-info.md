## Recent updates

- **Stacked pull requests are generally available** (GitHub Changelog, Oct 6, 2026): break large changes into smaller pull requests that are reviewed independently and merged together. Rebase stack now keeps approvals and signed commits. Source: [Stacked pull requests generally available](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/).
- **Dynamic workflows in Copilot CLI and the Copilot app** (GitHub Changelog, Oct 1, 2026): define multi-step, multi-agent work in code so the same steps run every time, with checkpoints you can review. Source: [Dynamic workflows in Copilot CLI and the Copilot app](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app/).
- **Daily Issues Report workflow** (Awesome Copilot): a weekday agentic workflow that posts a summary of open issues and recent activity as a GitHub issue. Source: [daily-issues-report.md](https://github.com/github/awesome-copilot/blob/main/workflows/daily-issues-report.md).
